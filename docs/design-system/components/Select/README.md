# Select

`.sel` з кнопкою `.trig` і списком `.list`.

- Список відкривається шторкою `clip-path` кроками `steps(6)` за 240 мс, стрілка обертається `steps(4)`.
- Відкритий стан: рамка `fg`, список приєднаний до кнопки без проміжку, радіус лише на зовнішніх кутах.
- Обраний пункт жирний. Праворуч у пункті можна показати строк міткою `px-11`.
- На телефоні замість списку нижня шторка з тими самими пунктами.
- Вибір картки пакета на сторінці заповнює цей список у формі.
