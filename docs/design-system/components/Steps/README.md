# Steps

`.steps`: 5 етапів у рядок (на телефоні стовпчиком). Стан етапу: `.ok` (мітка `accent`), `.now` (фон `surface2`, мітка `spark`), без класу (попереду).

- Мітка «01 / готово», «03 / зараз». Назва етапу `t-16` display, опис `t-13`.
- Опис поточного етапу друкується терміналом (`Mikaido.type`).
- На головній етапи проходять циклом близько 30 с: 5 × 5 с, успіх 3 с, пауза.
