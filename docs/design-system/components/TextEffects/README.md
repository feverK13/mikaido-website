# TextEffects

`Mikaido.decode(el)` і `Mikaido.type(el)`. Текст береться з `data-t`.

- Розшифрування: 900 мс, один раз, лише заголовок першого екрана. Ще не відкриті літери показані піксельним шрифтом `muted`.
- Друк термінала: до 50 знаків і до 3 с. Для кроків процесу, підписів, міток і повідомлень форми.
- Курсор, що блимає, один на сторінку.
- З «менше руху» текст з'являється одразу.
