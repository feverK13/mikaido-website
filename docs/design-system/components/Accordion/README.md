# Accordion

`.acc` з кнопками `.q` (`aria-expanded`) і панелями `.a`.

- Питання `t-16` display, відповідь `t-16` `muted`, до 62 знаків у рядку.
- Розкриття через `grid-template-rows` кроками `steps(6)` за 240 мс, іконка плюс ↔ мінус.
- Відповіді на FAQ формулюйте з чинних умов, без обіцянок, яких немає в договорі.
- У shadcn/ui це Accordion, перемалюйте за цими правилами.
