# Term

Піксельні мітки на `font-px`.

- `.term` (`px-22`) і `.term.s` (`px-11`): строки, дати, ключові терміни. Фон `tag`, скошений кут 10 × 4 px.
- `.stat`: стан етапу з квадратною точкою 6 px; `.stat.now` блимає `spark` кроком `steps(1)`.
- `.tabx` / `.sh .tab`: вкладка секції «/03 Кейси» над заголовком, заливка `fg`.
- `.num`: лічильники «01 / 05».
