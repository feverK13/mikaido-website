# Header

`.hdr` з `.lk` (знак + `.wm`), `.nav` і `.acts`.

- Знак веде на головну. Графіт у світлій темі, срібло в темній (`Mikaido.markAt(38, {metal})`).
- Активний пункт `aria-current="page"`: колір `fg` і підкреслення 2 px, що виростає кроками `steps(6)` за 240 мс.
- Пункти: Пакети, Процес, Кейси, Умови. Не більше 5.
- Липка шапка з фоном `bg` 92% прозорості і лінією `fg` знизу. На телефоні (до 860 px) навігація й кнопка A ховаються в меню-шторку.
