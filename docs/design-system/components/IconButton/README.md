# IconButton

Квадратна кнопка `.ib` 44 × 44 px з іконкою 24 px з `Mikaido.pix(name)`.

- Обов'язково `aria-label` з назвою дії («Змінити тему», «Меню», «Закрити»).
- Рамка `line2`, наведення `fg` + `surface2`, натискання зсув 1 px і фон `line`.
- У шапці кнопка теми має висоту кнопки поруч (`aspect-ratio: 1`), на телефоні не менше 44 px.
