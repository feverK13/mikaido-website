# PackageCard

`.pk` у сітці `.pks` (4 колонки → 2 → 1). Частини: `.a` (назва `px-33`, для кого), `.pr` (ціна `h-24`), `.sp` (рядки умов), `.ct` (дії).

- Пакети: Старт, Бізнес, Профі, Каталог. Ціни й строки беріть лише з чинного прайсу.
- Обрана картка `.on`: рамка 2 px `fg` і скошений кут-прапорець. «Обрати» вибирає пакет у формі і прокручує до неї.
- Наведення (лише `hover:hover`) показує той самий кут.
- На головній пакети показані консоллю з меню і голограмою, повна таблиця на сторінці «Пакети й умови».
