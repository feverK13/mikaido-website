# Toggle

`.tg` з `role="switch"` і `aria-checked`. 46 × 26 px, квадратний повзунок 16 px.

- Лише для дій, що діють одразу і легко скасовуються: категорії cookies, тема, сповіщення. Якщо потрібне підтвердження, ставте Checkbox.
- Поруч завжди текст, що вмикається. Вимкнено: фон `surface2`, повзунок `muted`. Увімкнено: фон `fg`, повзунок `bg`, рух `steps(4)` за 160 мс.
- «Завжди увімкнено»: `disabled`, прозорість 55%. Помилка: рамка `spark` і текст.
- На телефоні зона натискання розширена до 44 px.
- У shadcn/ui це компонент Switch, перемалюйте його за цими правилами.
