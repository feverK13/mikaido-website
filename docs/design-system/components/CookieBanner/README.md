# CookieBanner

`.ck` знизу екрана (на телефоні на всю ширину, до 40% висоти) і вікно налаштувань `.cs` з категоріями та Toggle.

- «Прийняти всі» і «Лише необхідні» однакові `.btn`. Кнопку A тут не ставимо: вона підштовхувала б до згоди.
- До вибору вантажаться лише необхідні cookies. Прокрутка не вважається згодою.
- З'являється через 1 с шторкою `steps(6)` за 240 мс, зникає миттєво.
- Вибір зберігаємо 12 місяців. «Налаштування cookies» у підвалі відкриває вікно знову.
- Категорії: Необхідні (завжди увімкнені) і Аналітика.
