# Icons

`Mikaido.pix(name, cls)` повертає SVG іконки 12 × 12 з `currentColor`. Файли SVG лежать у групі Icons.

- Розміри 24 і 48 px. Колір від тексту поруч.
- Піксель «o» (клас `o`) показує активний стан і фарбується `spark`.
- Нові іконки малюйте на сітці 12 × 12 рядками з «X» і «o», центр рахується за межами малюнка.
