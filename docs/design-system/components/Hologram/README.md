# Hologram

`Mikaido.HOLO.mount(canvas, model, "vox", {dark, base: "grid", scan: true, noGlitch: true})`, потім `HOLO.start()`.

- Моделі: `page` (Старт), `calendar` (Бізнес), `nodes` (Профі), `box` (Каталог).
- Основа: сітка точок, що обертається разом із предметом, і смуга сканування (варіант E). Без glitch. Запасний варіант: лише сітка (`scan: false`).
- Одна голограма на екран. Ніколи фоном.
- На телефоні 20 кадрів/с і без реакції на палець. З «менше руху» показується нерухомий кадр.
