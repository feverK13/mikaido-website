# Field

`.fld` з `label`, `input` або `textarea`, підказкою `.hint` і повідомленням `.msg`.

- Підпис завжди над полем (`t-13`, `muted`). Необов'язкове поле позначайте словом «необов'язково» праворуч.
- Рамка `line3`, фокус `accent` + м'яке кільце 3 px. Помилка: рамка й повідомлення `spark`, текст пояснює, як виправити.
- Телефон: формат +380, 12 цифр, `inputmode="tel"`, перевірка при втраті фокуса.
- Текстове поле росте з текстом (`resize: none`), ліміт 240 знаків. Лічильник `px-11`: від 200 знаків `fg`, на 240 `spark`.
- Шрифт у полях 16 px, щоб телефон не збільшував сторінку.
