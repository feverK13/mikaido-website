# PixelEffects

`Mikaido.dissolve(canvas, {color, dir})` і `Mikaido.dither(canvas, {dark})`.

- Розчинення: полотно поверх блоку зникає за матрицею Байєра 4 × 4, 650 мс (телефон 450 мс, клітинка 8 px), коли блок видно на 25%. Один ключовий блок у секції, по одному на екран, один раз.
- Також для перемикання вкладок і переходу між сторінками. Не для абзаців, форм, юридичних сторінок і підвалу.
- Піксельний градієнт замінює всі плавні градієнти: смужка ірису в підвалі, на картинці для посилань, на обкладинці брошури.
