# Alert

`.al` зі змінною `--c` (колір стану), іконкою, заголовком, поясненням і кнопкою закриття.

- Інформація `accent` + іконка info, успіх `fg` + check, помилка `spark` + alert. Стан завжди має слово й іконку, не лише колір.
- Заголовок каже, що сталося, пояснення каже, що робити далі.
- Текст повідомлення форми може з'являтися друком термінала (`Mikaido.type`), до 50 знаків.
