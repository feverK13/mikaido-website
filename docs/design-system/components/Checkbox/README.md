# Checkbox

`.chk` (прапорець) і `.chk.rd` (радіо). Справжній `input` прихований, видно `.bx`.

- Прапорець 20 × 20, рамка `line3`; вибраний: заливка `fg`, піксельна галочка `bg`.
- Радіо восьмикутне, точка-восьмикутник з'являється кроками `steps(2)`.
- Згода на обробку даних у формі обов'язкова, з посиланням на політику. Помилка: рамка `spark` і текст під прапорцем.
- Уся смуга з текстом натискається.
