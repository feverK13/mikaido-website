# Icons

Піксельні іконки 12 × 12 у SVG, чорнило #111216, активний піксель #A8396F (`spark`). У коді беріть `Mikaido.pix(name)`, щоб колір ішов від `currentColor`.

Розміри 24 і 48 px, `shape-rendering: crispEdges`. Назви: calendar, page, phone, chat, bars, search, cart, box, card, globe, server, shield, bell, report, arrow, check, menu, close, plus, minus, info, alert, theme.
