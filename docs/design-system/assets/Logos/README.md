# Logos

Знак Mikaido: окуляри-візор у кольорах ірису на двох металевих «ногах».

- `mikaido-mark-graphite.svg`: основний знак для світлого фону (від 120 px, метал і скло).
- `mikaido-mark-silver.svg`: основний знак для темного фону і картинки для посилань.
- `mikaido-mark-flat.svg`: пласка версія 48–119 px, ноги контуром.
- `mikaido-mark-small.svg`: до 48 px (шапка, документи), ноги суцільні.
- `mikaido-mark-mono-black.svg` і `mikaido-mark-mono-white.svg`: одноколірні, для печаток, тиснення, факсу. Чорнило #111216 або #FFFFFF.
- `mikaido-favicon-pixel.svg`: піксельний знак 16 × 16 для фавікона.
- Поруч зі знаком назва MIKAIDO шрифтом Unbounded 600, великими літерами, трекінг 0,06 em.
- Поле навколо знака не менше висоти візора. Не перефарбовуйте, не повертайте, не додавайте тіні.
